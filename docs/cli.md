## `beancount-envelope-budget pool`

| Option | Help |
| --- | --- |
| `-h, --help` | show this help message and exit |

| `--json` | print the ledger as JSON instead of a table |

## `beancount-envelope-budget pin`

Print a diff that adds the resolved envelope to matching postings as posting metadata, so you can then change the account's envelope without altering history. Postings that already carry an envelope are skipped, and plugin or importer entries cannot be pinned.


| Option | Help |
| --- | --- |
| `-h, --help` | show this help message and exit |
| `ledger` | path to the Beancount ledger (.bean or .beancount) |
| `--account` | only pin postings whose account matches this regular expression |
| `--through` | only pin postings dated on or before this date |
| `--apply` | edit the ledger files in place instead of printing a diff |

## `beancount-envelope-budget consolidate`

Print a diff that merges an envelope-month's several allocate directives into a single directive, dated the last day of the month (or today, for the current month). The net amount is unchanged, so balances, the pool and the invariant are unchanged. With no filter the whole ledger is consolidated; --envelope limits it to matching envelopes, and --month to a single month. A month with a single directive is left alone. Apply the diff with --apply.


| Option | Help |
| --- | --- |
| `-h, --help` | show this help message and exit |
| `ledger` | path to the Beancount ledger (.bean or .beancount) |
| `--envelope` | only consolidate envelopes whose name matches this regular expression |
| `--month` | only consolidate this month |
| `--apply` | edit the ledger files in place instead of printing a diff |

## `beancount-envelope-budget clear`

Print a diff that deletes every allocate directive in a month or matching an envelope, so the month can be funded again from scratch. The funds return to the pool. At least one of --month or --envelope is required. A directive without a source location is reported and left alone. Apply the diff with --apply.


| Option | Help |
| --- | --- |
| `-h, --help` | show this help message and exit |
| `ledger` | path to the Beancount ledger (.bean or .beancount) |
| `--envelope` | only clear envelopes whose name matches this regular expression |
| `--month` | only clear this month |
| `--apply` | edit the ledger files in place instead of printing a diff |
