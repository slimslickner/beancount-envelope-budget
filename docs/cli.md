## `beancount-envelope-budget pool`

Print every transaction and allocation that moved the unassigned pool, in date order with the running balance after each, so a negative pool (W001) can be traced. A bare run shows the pool's lowest month when it ever went negative, else the latest month.


| Option | Help |
| --- | --- |
| `-h, --help` | show this help message and exit |
| `ledger` | path to the Beancount ledger (.bean or .beancount) |
| `--all` | show the pool's whole history instead of a single month |
| `--month` | show one month of the pool's ledger |
| `--date` | show one day of the pool's ledger, with its opening balance |
| `--json` | print the ledger as JSON instead of a table |

## `beancount-envelope-budget fund`

Print allocate directives, dated the last day of each month. The actuals, overspend and copy modes take --from/--to and skip any envelope-month that already has an allocation; topup, fully-fund and fund-available take --date.


| Option | Help |
| --- | --- |
| `-h, --help` | show this help message and exit |
| `ledger` | path to the Beancount ledger (.bean or .beancount) |
| `--from` | first month to fund (required for actuals, overspend and copy) |
| `--to` | last month to fund (required for actuals, overspend and copy) |
| `--mode` | the funding strategy: actuals, overspend, copy, topup, fully-fund or fund-available |
| `--envelopes` | only fund envelopes whose name matches this regular expression |
| `--force` | print allocations even for months that already have one |
| `--date` | the date to fund for topup, fully-fund and fund-available |
| `--reserve` | cash to keep unallocated in the pool (topup, fund-available) |
| `--strict` | exit non-zero when a funding run leaves anything unfunded |
| `--write` | append the directive(s) to this file (relative to the ledger's directory) instead of printing them; the ledger is reloaded after |

## `beancount-envelope-budget pin`

Print a diff that adds the resolved envelope to matching postings as posting metadata, so you can then change the account's envelope without altering history. Postings that already carry an envelope are skipped, and plugin or importer entries cannot be pinned.


| Option | Help |
| --- | --- |
| `-h, --help` | show this help message and exit |
| `ledger` | path to the Beancount ledger (.bean or .beancount) |
| `--account` | only pin postings whose account matches this regular expression |
| `--through` | only pin postings dated on or before this date |
| `--write` | edit the ledger files in place instead of printing a diff |
