# Schema

> Generated by `beancount-envelope-budget docs`. Do not edit by hand.

Every `custom "envelope"` directive verb, metadata key and reserved value the plugin understands.

## Directive verbs

### `start`

Start of tracking. Earlier postings and allocations are ignored; the pool starts at the cash balance just before this date.


Metadata: none.

### `open`

Declares an envelope.


| Argument | Kind | Required | Description |
| --- | --- | --- | --- |
| `envelope` | string | yes | The name of the envelope to declare. |


Metadata: `monthly`, `up-to`, `priority`, `goal`, `by`, `parent`.

### `allocate`

Moves money from the pool into an envelope, dated the directive's own month.


| Argument | Kind | Required | Description |
| --- | --- | --- | --- |
| `envelope` | string | yes | The envelope to fund. |
| `amount` | amount (number and currency) | yes | The amount moved from the pool into the envelope. A negative amount moves money back to the pool. |


Metadata: none.

### `close`

Retires an envelope. Its balance must be zero, and it disappears from reports afterwards.


| Argument | Kind | Required | Description |
| --- | --- | --- | --- |
| `envelope` | string | yes | The envelope to retire. |


Metadata: none.

### `plan`

Changes an envelope's plan from that date. It takes the same metadata as `open` and changes only the fields it names; the latest plan on or before the run date wins.


| Argument | Kind | Required | Description |
| --- | --- | --- | --- |
| `envelope` | string | yes | The envelope the plan applies to. |


Metadata: `monthly`, `up-to`, `priority`, `goal`, `by`.

### `unplan`

Clears an envelope's plan from that date, so no funding is planned for it. Its balance and its presence in reports are unaffected.


| Argument | Kind | Required | Description |
| --- | --- | --- | --- |
| `envelope` | string | yes | The envelope to clear the plan from. |


Metadata: none.

## Metadata keys

| Key | Kind | Required | Default | Applies to | Meaning |
| --- | --- | --- | --- | --- | --- |
| `envelope` | string | no | — | account open, transaction, posting | The envelope an account's or posting's effects belong to. The reserved value pool sends them to the pool instead. |
| `cash-account` | boolean | no | — | account open | TRUE marks an Assets or Liabilities account as spendable cash whose balance counts toward the pool. FALSE is the same as leaving the key out. |
| `monthly` | number or "avgN" | no | — | envelope open, envelope plan | The planned monthly funding amount, or "avgN" for the average of the last N completed months of spending. |
| `priority` | decimal | no | — | envelope open, envelope plan | Lower numbers fund first during topup. Ties fund in declaration order; envelopes without a priority fund last. |
| `goal` | amount (number and currency) | no | — | envelope open, envelope plan | A savings goal: the total to contribute by its `by` date, e.g. 15000.00 USD. Funded by cumulative contributions, not the balance, so spending does not un-fund it. |
| `by` | date | no | — | envelope open, envelope plan | The date by which the goal should be reached, e.g. 2028-06-01. |
| `up-to` | decimal | no | — | envelope open, envelope plan | A balance ceiling paired with `monthly`: fund by the monthly amount each month, but never above this balance. Requires `monthly` and is mutually exclusive with `goal`. |
| `parent` | string | no | — | envelope open | A grouping label. Envelopes with the same parent are shown together under a heading, with a subtotal of their balances. |


## Reserved values

| Value | Meaning |
| --- | --- |
| `pool` | Send an account's or posting's effects to the unassigned pool instead of an envelope. |
