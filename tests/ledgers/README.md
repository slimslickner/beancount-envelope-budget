# Test fixtures

One Beancount fixture ledger per case in the specification's test list lives
here, alongside the expected results asserted in `tests/test_core.py`.

`sample.bean` is different: it is generated by `scripts/sample_ledger.py`, loads
with no diagnostics, and demonstrates every feature (all plan kinds, life-cycle
events, overrides and the reserved `pool` value) in one ledger. Regenerate it
after changing the generator; `tests/test_sample.py` checks it is current.
